# 简历表单助手

Chrome/Edge Manifest V3 扩展。资料和附件保存在本机浏览器的扩展存储中。

## 使用

1. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。
2. 选择“加载已解压的扩展程序”，选中本目录。
3. 在扩展弹窗点“编辑资料”，填写并保存。可以点“预览简历”检查内容。
4. 打开招聘表单，点击扩展中的“填入当前页面”，检查后自行提交。

单值字段及识别词维护在 `fields.js`；可逐条新增的教育、工作/实习、项目、获奖/证书字段维护在 `records.js`。当前支持普通文本框、多行文本框、原生下拉框、单选/复选框、可编辑区域和原生文件上传。重复经历需要页面有可识别的区块标题和字段标签；插件会在该区块内寻找“新增”按钮并按顺序填写。网站自绘的下拉框、验证码、跨域受限框架和特殊上传组件可能需要针对网站适配。扩展存储有容量上限，附件过大时保存会失败。

首次运行会从 `defaults.js` 载入随附简历中的资料，并将 `default-resume.pdf` 作为默认附件。升级到 0.2.0 后首次打开资料页，会将旧版整段经历迁移为可逐条编辑的记录；此前额外填写的整段内容会附在对应第一条记录的说明中。之后在资料页修改并保存的内容以浏览器本地存储为准。日期统一采用 `YYYY-MM-DD`，只知道年月时采用 `YYYY-MM`。原生日期控件需要完整年月日；缺少具体日期时插件会跳过该控件，不猜测某一天。
