# 简历表单助手

Chrome/Edge Manifest V3 扩展。资料和附件保存在本机浏览器的扩展存储中。

## 使用

1. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。
2. 选择“加载已解压的扩展程序”，选中本目录。
3. 在扩展弹窗点“编辑资料”，填写并保存。可以点“预览简历”检查内容。
4. 打开招聘表单，点击扩展中的“填入当前页面”，检查后自行提交。

单值字段及识别词维护在 `fields.js`；可逐条新增的教育、工作/实习、项目、获奖/证书、在校职务字段维护在 `records.js`。填表器从同一字段行的文字、关联标签和附近文本识别输入框，按区块处理重复经历。支持普通文本框、多行文本框、原生下拉框、部分自绘下拉框、单选/复选框、可编辑区域和原生文件上传。验证码、部分日期选择器、跨域受限框架和特殊上传组件可能需要人工处理。扩展存储有容量上限，附件过大时保存会失败。

0.3.1 版会在表单控件上标记识别结果：绿色为已填入，橙色为资料未填，红色为控件暂不支持，灰色为未识别。弹窗的“查看识别明细与颜色说明”可复制不含填写内容的诊断报告，供后续改进规则。重新打开同一标签页的弹窗仍可查看最近一次报告。

0.3.2 版根据用户提供的诊断新增更多资料项。教育经历的“学习形式”暂按“全日制”作为默认值，可在资料页修改。原生 `month` 控件填 `YYYY-MM`；原生 `date` 控件要求 `YYYY-MM-DD`。只有年月而无具体日期时不会猜测某一天。用途不明的通用上传框不会自动上传简历文件。

首次运行会从 `defaults.js` 载入随附简历中的资料，并将 `default-resume.pdf` 作为默认附件。升级到 0.2.0 后首次打开资料页，会将旧版整段经历迁移为可逐条编辑的记录；此前额外填写的整段内容会附在对应第一条记录的说明中。之后在资料页修改并保存的内容以浏览器本地存储为准。日期统一采用 `YYYY-MM-DD`，只知道年月时采用 `YYYY-MM`。原生日期控件需要完整年月日；缺少具体日期时插件会跳过该控件，不猜测某一天。
